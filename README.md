# California_Housing_Pred_Model
California_Housing_Prediction_Model
## Project Overview

This project focuses on predicting house prices using the **California Housing dataset** and machine learning regression techniques.

The project covers data preprocessing, splitting the dataset into training and testing sets, feature scaling, model training, and model evaluation.

The goal is to understand how different housing features can be used to predict the median house value and to gain practical experience working with regression models in Python and Scikit Learn.
